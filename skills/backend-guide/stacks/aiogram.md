# aiogram 3

- Обработчики домена — `controllers/bot.py` (router), клавиатуры — `controllers/keyboards.py`,
  состояния FSM — `controllers/states.py`, если их ставит соседний код.
- Зависимости — `@inject` + `FromDishka[...]` (dishka.integrations.aiogram).
- **Сработавший обработчик (совпали фильтры) останавливает событие, даже если сделал `return`.**
  Поэтому доступ — фильтром (`HasAdminAccess()`), не `return` в теле (CTL-03).
- Порядок роутеров задаётся в одном месте сборки. Команды и кнопки домена — раньше
  обработчиков ввода; обработчики «поймать всё» — отдельным роутером в конце.
- В роутере ввода — только обработчики своих состояний.
- Префиксы `callback_data` у доменов не пересекаются; разбор — помощником с типами.
- Тесты — через настоящий диспетчер, сеть запрещена (сессия, падающая на любой запрос);
  тест на каждое пересечение: команда во время ввода, сценарий другого домена во время диалога.
- Отправка сообщений — после коммита (TX-02).
