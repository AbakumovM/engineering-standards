# FastStream (брокер)

- Обработчик сообщения — `controllers/broker.py`: разобрать → сценарий → ack (CTL-01).
- Обработчик идемпотентен: id сообщения/события в inbox-таблице или уникальный ключ
  результата, в той же транзакции, что и изменение (TX-10).
- Публикация — только через outbox и отдельный relay (TX-09); сценарий `publish()` не зовёт.
- Схема сообщения — версионируемый контракт в `public.py` домена-владельца события.
- Ретраи и dead-letter — настройкой брокера, не циклом в обработчике.
- Dishka: `dishka.integrations.faststream`, область REQUEST — на одно сообщение.
