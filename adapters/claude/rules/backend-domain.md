# Слой domain (каталог правил: backend-guide/catalog.md)

- Только стандартная библиотека и свой `domain` — ни ORM, ни pydantic, ни фреймворков (DEP-02).
- Правила — чистые функции/методы; «можно ли» возвращает причину отказа (DOM-01, DOM-02).
- Исключения — `{Что}{Проблема}Error` в `exceptions.py` (DOM-03).
- Новое правило про деньги, сроки, доступ — сразу с модульным тестом (TST-01).
