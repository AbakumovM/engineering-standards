# Слой controllers

- Разобрать → вызвать сценарий/View → ответить; ни одного бизнес-`if` (CTL-01).
- Не коммитит, не ходит в Gateway (TX-01).
- Внешние вызовы — до сценария или после коммита, порядок безопасен при сбое (TX-02, TX-03).
- Доступ — фильтром/зависимостью (CTL-03). Тексты, кнопки, схемы — здесь (CTL-02).
- Вебхук/обработчик события — идемпотентен (TX-10), подпись — по сырому телу (SEC-06).
- Схемы явные, `extra="forbid"`, потолки длин; ответ — из `Info` (API-01, API-07).
- Ошибки — общим обработчиком, единым форматом (API-02); список — `limit` + курсор (API-04).
- Создающий/платёжный `POST` — `Idempotency-Key` (API-05). Изменение схемы — совместимое (API-06).
- Субъект передаётся в сценарий; админское — роутер с ролью (SEC-01, SEC-02).
- Долгое — в очередь, ответ `202` (PERF-06). Подробно — `backend-guide/api.md`, `security.md`.
