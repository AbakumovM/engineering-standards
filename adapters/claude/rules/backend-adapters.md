# Слой adapters

- Реализует порт из `application/interfaces/`; `commit()` не вызывает (TX-01).
- Только таблицы своего домена; чужое — через `public.py` соседа (DEP-05).
- Ожидаемый конфликт уникальности — savepoint + доменное исключение (TX-07).
- Ошибки внешнего API — одним исключением порта (ADP-02); клиент — из infrastructure, не создавать (ADP-01).
- Агрегация и фильтрация — в SQL (ADP-04); нет запросов в цикле (PERF-01); массовое — пачками (PERF-08).
- Только параметризованный SQL (SEC-05); новый запрос по растущей таблице — с индексом (PERF-02).
- Метод «по id» принимает субъекта/владельца (SEC-01).
- Внешний вызов: таймаут, ограничение параллельности, повторы только идемпотентного (REL-02, PERF-05);
  ответ чужого API разбирается схемой (SEC-08).
