# Тесты фронтенда (подробно: frontend-guide/testing.md)

- Функции `model/` — модульные тесты: границы, каждая причина отказа (FTST-01).
- Компоненты — Testing Library по ролям и подписям, `userEvent`; без снапшотов деревьев (FTST-02).
- Сеть — MSW, `onUnhandledRequest: "error"`; не подменять `fetch` и клиент руками (FTST-03).
- Для каждого запроса — успех и ошибка (`422`/`409`/`500`); двойная отправка — один запрос.
- e2e — Playwright, локаторы по ролям, axe на странице (FTST-04, FA11Y-06).
- Тест прошёл с первого раза — сломать код и убедиться, что упал (FTST-05).
